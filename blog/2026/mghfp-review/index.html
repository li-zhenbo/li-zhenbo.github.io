综述：MGHFP 方法从提出到完善的演进路径——基于四篇系列论文的梳理

Created on July 28, 2026

2026   ·   paper-notes   ·   notes

摘要

非线性振子极限环的全局演化定量分析，因复杂恢复力或非线性阻尼导致的”符号化执行”困难，长期是摄动方法研究的瓶颈。2024–2026 年间，改进广义谐波函数摄动法（MGHFP）经由四篇系列论文完成了从首次提出到全面完善的演进。本文以这四篇论文为分析对象，系统梳理该方法的发展历程、核心框架与创新脉络，并结合流程图和对比表格，总结其在方法学、理论分析与工程应用三个层面的核心贡献。

1. 引言：定量分析为什么需要符号化？

非线性振子极限环的全局动力学分析——其诞生、数量、稳定性、振幅和临界分岔条件——是动力学理论的核心课题。大多数经典摄动方法在这一任务的最后一步”卡脖子”：其 Fourier 系数在恢复力或阻尼形式复杂时，涉及的积分无法解析计算，必须先为系统参数赋数值。其后果是方法退化为半解析，每个参数组合都需独立运行一次数值流程，既低效又无法获得全局的解析解图像。

MGHFP 方法的核心创新——将复合 Simpson 数值积分公式嵌入 GHFP 的流程——正是为了打破这一僵局。此后四篇论文层层推进，最终形成了一套能够覆盖从多项式到无理非线性耦合系统的完整分析框架。

2. 方法总览与演进主线

MGHFP 的统一框架包含四个步骤：

Step 1 非线性时间变换：用 $\frac{d\varphi}{dt} = \Phi(\varphi)$ 将含 $t$ 的振子方程转换为角域 $[0, \pi]$ 上对称周期的形式。

Step 2 Fourier 展开：假设解为 $x(\varphi) = a\cos^2\varphi + b$，并将 $\Phi(\varphi)$ 展开为 Fourier 级数 $\Phi(\varphi) = \sum_{i=0}^{M}(p_{2i}\cos 2i\varphi + q_{2i}\sin 2i\varphi)$。

Step 3 摄动展开：以阻尼强度 $\varepsilon$ 为小参数，写 $a = a_0 + \varepsilon a_1 + \cdots$，$\Phi = \Phi_0 + \varepsilon\Phi_1 + \cdots$，逐阶求解。

Step 4 复合 Simpson 积分：对于任意不可解析的函数 $f$，用 $\int_a^b f(x)dx \approx \frac{h}{3}[f(x_0) + 4\sum_{i:odd}f(x_i) + 2\sum_{i:even}f(x_i) + f(x_n)]$ 将积分离散化。选取 $n=18$ 个子区间，各 Fourier 系数 $p_i$ 便成为系统参数 ${c_i, \mu_i}$ 的显式代数函数——无需预赋任何数值即可推导出中心关系。

这一框架依序产生两个核心公式：振幅—参数关系（控制参数 $\mu$ 作为振幅 $A$ 及所有其他系统参数的显式函数）与稳定性特征量 $h_0(A)$。以两者为基础，令 $A$ 等于鞍点坐标即可进一步获得同宿或异宿分岔的临界参数。

3. 四篇论文的分阶段详述

3.1 阶段 I：方法提出（P1, 2024.06）

文献：Li, Hou, Zhang, Xu. Phys. Scr. 99, 075213.

对象系统：$\ddot{x} + c_1 x + c_3 x^3 + c_5 x^5 = \varepsilon(\mu + \mu_1 x + \mu_2 x^2 + \mu_3 x^3 + \mu_4 x^4 + \mu_{22} \dot{x}^2)\dot{x}$。该混合 Rayleigh–Liénard 振子的恢复力为纯多项式，阻尼同时包含 Rayleigh 项（$\dot{x}^2$）与 Liénard 项（$x, x^3$），6 个阻尼系数的组合使经典 GHFP 无法符号化推进。

里程碑：(i) 首次公开提出 MGHFP 方法及其”复合 Simpson 积分 + GHFP”的公式体系；(ii) 首次从纯符号化角度推导出 $\mu(A)$ 和 $h_0(A)$ 的完整表达式；(iii) 在单阱条件下实现了最多三个极限环共存的完整定量分析；(iv) 在三阱条件下同时预测了同宿与异宿分岔的临界参数。

3.2 阶段 II：推广至有理恢复力（P2, 2024.07）

文献：Li, Cai, Hou. Int. J. Non-Linear Mech. 166, 104832.

对象系统：$\ddot{x} + \frac{\lambda x + \mu x^3}{1 + \nu x^2} = \varepsilon(\mu_c + \mu_2 x^2 + \mu_4 x^4 + \mu_6 x^6 + \mu_{22} \dot{x}^2 + \mu_{24} \dot{x}^4)\dot{x}$。该广义 DHRL 振子的恢复力为分母含 $\nu x^2$ 项的有理函数，相比于 P1 的纯多项式，Fourier 系数计算的复杂度在代数上显著提高；阻尼项也扩展到 6 项。

里程碑：(i) 首次验证 MGHFP 可处理分母含 $x^2$ 的有理非线性恢复力，从纯粹的数值积分跨越到符号化代数；(ii) 在 $\mu_c$–$A$ 曲线中识别出四区域结构（I: 无极限环 → II: 稳定 + 不稳定共存 → III: 另一稳定 + 不稳定结构 → IV: 单一稳定）；(iii) 三阱势条件下同宿与异宿分岔的预测再次成功，说明框架对不同恢复力形式具备鲁棒性。

3.3 阶段 III：Padé 增强与多参数扩展（P3, 2025）

文献：Li, Hou, Peng. Int. J. Non-Linear Mech. 178, 105185.

对象系统：SD 振子，$\ddot{x} + \omega_0^2 x(1 - 1/\sqrt{x^2+\alpha^2}) = \varepsilon(\mu_c + \mu_1 x + \mu_2 x^2 + \mu_3 x^3 + \mu_4 x^4)\dot{x}$。这是 MGHFP 首次应用于无理非线性——恢复力含平方根，其 Taylor 展开是无限级数。阻尼提高到四次（$\mu_4 x^4\dot{x}$），在高阶 MEMS 和隔振器中为常见形式。

里程碑：(i) 引入 Padé 近似 $f(\alpha, A) \approx P_n(\alpha, A)/Q_m(\alpha, A)$，将前两篇输出中过于复杂的嵌套 Simpson 积分拟合为简单的有理函数，大幅降低实用门槛；(ii) 首次实现多参数极限环分析——此前只能逐参数讨论，现在 $\mu_c$ 对 $(\mu_1,\mu_2,\mu_3,\mu_4,\alpha)$ 的联合依赖关系可同时解析描述；(iii) 推导出”Theorem 2 & 3”——振荡器恰好拥有两个极限环的完整参数区域——在 P1/P2 的框架下这在代数上只是统计结果，但在 Padé 之后变成分析定理。

3.4 阶段 IV：双无理耦合多阱系统（P4, 2026）

文献：Li, Hou, Peng. Phys. Scr. 101, 125205.

对象系统：耦合 SD 振子，$\ddot{x} + (x+\beta)/\sqrt{(x+\beta)^2+\alpha^2} + (x-\beta)/\sqrt{(x-\beta)^2+\alpha^2} = \varepsilon(\mu_c + \mu_1 x + \mu_2 x^2 + \mu_3 x^3 + \mu_4 x^4)\dot{x}$。双无理项为系列中的最高复杂度——Fourier 系数计算需在高维参数空间中对两个独立平方根项同时做 Simpson 离散，误差传播是单无理项场景的数倍。

里程碑：(i) MGHFP 首次成功应用于含两个无理非线性项的耦合系统，证明其通用性和可扩展性；(ii) 三阱势+双无理项的耦合使系统可同时容纳小极限环（同宿轨道内）、大极限环（全空间）和异宿轨道（跨鞍点连接），MGHFP 在最高维度的参数空间中依然能提供全部同异宿分岔的预测；(iii) 标志着该系列方法覆盖了从多项式恢复到双无理耦合系统的完整对象谱系。

5. 讨论与贡献

5.1 方法学层面

MGHFP 解决了非线性摄动方法论的核心缺陷——在复杂振子上无法进行完全分析的”符号化执行”。复合 Simpson 积分是开锁的钥匙：它将不解析积分转化为对参数的无条件代数运算。Padé 近似在后端将表达式进一步压缩为可用的闭型有理函数，同时将其从仅有数值形式的”单参数产物”升级为真正的”多参数分析工具”。

5.2 理论分析层面

经由四篇论文，分析师从同一框架获得以下能力：(i) 极限环的全生命周期定量预测，即从半稳定生成到稳定性分岔直至终止；(ii) 在任何指定的参数面上的全局演化图像；(iii) 同宿和异宿分岔临界参数的解析判定（其为混沌出现的先导，赋予该工具预测控制器设计的直接意义）。

5.3 工程应用层面

从 $\mu(A)$ 出发可直接设计放大器控制策略——在惯性激振器或种群动力学中维持指定振幅的极限环；从 $h_0(A)$ 和同异宿阈值出发可确定混沌发生的边界，用于加密或设备保护。该体系已在 MEMS、准零刚度隔振、能量采集等实际系统中演示了可移植性。

6. 结论与展望

四篇论文构成的 MGHFP 系列，从方法提出到多参数推广，在不到两年的时间内完成了从极限环全局定量分析到双无理非线性耦合系统的完整覆盖。从解析方法的知识体系来看，这套工具填补了旧有 GHFP 族方法无法在复杂振子上符号化执行的长期空白，并提供了从定性讨论到全局定量预测的跨越路径。

未来可能的发展方向包括：(i) 向多自由度耦合系统（如 Coupled van der Pol–Duffing 振子）的推广；(ii) 高阶摄动展开对大扰动条件下精度的修正；(iii) 利用机器学习加速复合 Simpson 积分的子区间优化或 Padé 系数的自动生成，为进一步扩大该方法的复杂度边界提供辅助。
